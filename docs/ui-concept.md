# Концепция интерфейса Домового — описание для оценки

Документ описывает, **как устроен интерфейс и почему именно так** — не архитектуру движка (это [`ui-architecture.md`](ui-architecture.md)), а то, что видит и делает пользователь. Все утверждения пронумерованы (`П-1`…`П-24`) — правь ссылками на номера: «П-7 не так, хочу …».

Текущее состояние: этапы A и A2 задеплоены на https://v1.spiridus.ru; чего ещё нет — помечено ⏳.

---

## 1. Ядро: три идеи

**П-1. Всё — узлы одного склада.** Вещь, полка, гараж, холодильник, человек, документ, папка, список — узлы одного графа. В интерфейсе нет «разделов приложения» — есть узлы и переходы между ними.

**П-2. Каждый узел — экран.** Открыть узел = войти в него. Экран любого узла устроен одинаково:

```
[трейл: путь, которым пришёл]
[шапка: название, чипы (категория, статус, бренд…)]
[грид: содержимое узла иконками]        ← если есть содержимое
[свойства: описание, где находится, документы, поля]
```

Гараж, папка «Техника», холодильник, NUC — один и тот же паттерн. Разного «UI под фичи» нет.

**П-3. Один узел — много мест (симлинки).** Узел может быть размещён где угодно и сколько угодно раз: холодильник живёт в Кухне (физически) и на рабочем столе (ярлык). Везде — один и тот же узел; удаление ярлыка никогда не удаляет узел.

## 2. Навигация

**П-4. Главная `/` — рабочий стол**: грид иконок (места, папки, списки, отдельные вещи, Мурка). Это твоя точка входа, состав — полностью твой.

**П-5. Навигация = хождение по графу.** Тапнул иконку → вошёл внутрь. Внутри гаража — верстак и шкафы, внутри верстака — инструменты, у инструмента — карточка. «Вверх» — по трейлу.

**П-6. Трейл (хлебные крошки) — это фактический путь, которым ТЫ пришёл**, а не «истинное место» узла. У узла в графе много родителей, единственного пути нет; поэтому крошки запоминают навигацию (🏠 сбрасывает). ⏳ Рядом с трейлом позже появится «где ещё размещён узел».

**П-7. Списки — тоже узлы.** «Все вещи», «Одолжено» — иконки на столе; внутри — таблица. Кликабельно всё, что имеет имя.

**П-8. ⏳ Поиск** (этап B): `/` с клавиатуры → строка поиска → Enter на топ-результате. Задуман как главный способ «найти конкретное», грид — способ «осмотреться и разложить».

## 3. Содержимое узла: что попадает в грид

**П-9.** В грид экрана попадают, в этом порядке:
1. **размещения** — то, что ты положил сюда сам (рёбра `references`, со слотами);
2. **под-локации** — вложенные места (верстак внутри гаража);
3. **физическое содержимое** — что лежит/установлено внутри (`contains`), включая «установлено» у комплектующих (SSD в NUC).

**П-10.** Раскладывать вручную (слоты, пустые места) можно только **размещения на столах/папках**. Содержимое гаража тасовать нельзя — его порядок идёт от данных (⏳ сортировки/группировки для таких экранов — этап B).

## 4. Рабочий стол, папки, слоты

**П-11. Сетка — разреженная, со слотами.** Каждая иконка занимает ячейку; пустые ячейки — легитимны и сохраняются. Автоматического уплотнения нет: сортировка только ручная («сортировкой рулю я»).

**П-12. Ширина сетки** — 8 колонок (настройка `grid_cols` пер-стол; UI-ручки пока нет ⏳). На телефоне ячейки ужимаются, раскладка сохраняется (не перетекает).

**П-13. Папка = такой же узел-стол.** Вложенность любая. Папку можно шарить, переименовывать (✏️), размещать в нескольких местах.

## 5. Режимы: просмотр и «Изменить»

**П-14. В режиме просмотра ничего нельзя сломать.** Перетаскивание выключено; клик — только переход. Это защита от случайного тача.

**П-15. Кнопка «Изменить»** над гридом (только на столах/папках) включает режим редактирования; «Готово» выключает.

**П-16. Жесты режима «Изменить»:**

| Жест | Действие |
|---|---|
| клик по иконке | выбрать / снять (✓) |
| shift-клик | выбрать диапазон подряд |
| тянуть выбранное → пустая ячейка | перенос выделения (первая — в ячейку, остальные — в свободные за ней) |
| тянуть → на иконку, **держать ~0.7с** (янтарная подсветка) | обычная иконка → новая папка с обоими; папка → перенос внутрь |
| тянуть → на иконку, бросить сразу | перенос в её слот (без папки) |
| кнопка «В папку» | папка из выделения |
| кнопка «Разместить ещё в…» | симлинки выделения в выбранный стол/папку |
| кнопка «Убрать» | убрать размещения (узлы живы) |

**П-17.** ⏳ На тач-экранах режим «Изменить» пока ограничен (нет long-press, dnd ненадёжен) — мобильные жесты в этапе H.

## 6. Иконки и подписи

**П-18.** Иконка узла выбирается по цепочке: своё поле `icon` (можно задать любому узлу; UI-ручки пока нет ⏳) → эмодзи категории (🧊 холодильник, 🛠 инструмент) → эмодзи типа (📦 место, 💻 девайс, 📁 папка). Эмодзи — временные; ⏳ нормальная иконотека/фото вещей — отдельным шагом.

**П-19.** Подпись = имя узла (или его перевод из словаря). Бейдж «установлено» — у комплектующих внутри устройств.

## 7. Карточка (свойства узла)

**П-20.** Блок свойств под гридом собирается **из каталога, не из кода**: для каждого типа узла в графе описано, какие виджеты показывать (категория, статус с цветом, бренд, «где находится», «одолжено», документы…). Пустое не показывается. Незнакомый тип получает generic-вид (все поля таблицей) — система не падает и не прячет данные.

**П-21.** Подписи и цвета (типов, категорий, статусов) приходят из словарей графа с переводами — в коде интерфейса этих строк нет. Переключатель языка — ⏳ этап E.

## 8. Чего сознательно нет (и почему)

**П-22. Нет сайдбара и «разделов».** Раньше был (`/w/sklad`) — убран по твоему же запросу единой концепции. Роль навигации несут стол, трейл и (⏳) поиск.

**П-23. Нет свободного канваса (x,y).** Слоты — сетка, а не «куда угодно попиксельно»: переживает смену ширины экрана и мобильный. (Решение D-53/D-55; если нужен именно канвас — это правка концепции.)

**П-24. Нет автосортировок на столах.** Даже «по алфавиту» кнопкой — пока нет ⏳; авто-сортировка **по умолчанию** противоречила бы «сортировкой рулю я», но опциональная кнопка возможна.

## 9. Известные шероховатости (кандидаты на правку — оцени)

| # | Что | Варианты |
|---|---|---|
| Ш-1 | Свойства узла под гридом могут мешать на «складских» экранах | сворачивать по умолчанию / таб «Свойства» / оставить |
| Ш-2 | Вход в режим «Изменить» кнопкой — а привычнее long-press по иконке? | добавить long-press как второй вход |
| Ш-3 | Жест «папка через удержание 0.7с» — неочевиден без подсказки | + пункт «Создать папку» всегда в панели (есть «В папку» при выделении) |
| Ш-4 | Быстрый дроп на занятую иконку = «перенос в её слот» — возможно, интуитивнее «поменять местами» | swap vs push |
| Ш-5 | 8 колонок фиксировано | ручка ширины на столе; крупные/мелкие иконки |
| Ш-6 | Трейл-крошки исчезают после закрытия вкладки (sessionStorage) | ок для трейла? постоянную «карту мест» дадут симлинки-родители (П-6 ⏳) |
| Ш-7 | На экранах-списках («Все вещи») концепция «узел-экран» вырождается в таблицу без шапки | добавить шапку-карточку и списку |
